# Minecraft 3D Skin Layers for MCprep

[中文](README.md)

> A Blender add-on that adds renderable 3D outer skin layers to Minecraft player models generated by MCprep.

The outer skin is generated as real voxel-based geometry from the skin texture, rather than duplicating or thickening MCprep's existing Layer2 shell.

---

## Features

- Generates real 3D outer skin geometry from the skin texture
- Supports MCprep's **Simple Player** model
- Supports MCprep's **Simple Player Slim** model (detected automatically)
- Detects the currently selected player model automatically
- Independent control over **Head / Body / Arms / Legs**
- **Generate / Rebuild / Delete** the 3D outer layers
- Handles skins with transparent regions
- Handles multiple player models in the same scene, each processed independently
- **Pose-friendly:** adjust the character in Pose Mode while the 3D outer layers remain associated with their corresponding body parts and preserve their structure during normal posing
- **Non-destructive**: never modifies MCprep's Layer1 / Layer2, armature, materials or skin images

## Installation

1. Go to [Releases](../../releases) and download `minecraft_3d_skin_layers-v1.0.0_en.zip`
2. Open Blender
3. Go to **Edit → Preferences → Add-ons**
4. Click **Install…**
5. Select the `minecraft_3d_skin_layers-v1.0.0_en.zip` you just downloaded
6. Enable **Minecraft 3D Skin Layers for MCprep** in the list

> Do not download the "Source code" ZIP that GitHub generates automatically — it cannot be installed.

---

## Usage

1. Create a Minecraft player model with MCprep
2. Select that player model, or any of its parts
3. Press **N** in the 3D Viewport to open the sidebar
4. Open the **MC 3D Skin Layers** tab
5. Tick **Head / Body / Arms / Legs** as needed
6. Click **Generate 3D Layers**

What the three buttons do:

| Button | Action |
| --- | --- |
| **Generate 3D Layers** | Creates the parts that do not exist yet; existing parts are left untouched |
| **Rebuild 3D Layers** | Deletes this add-on's layers, then regenerates them using the current selection |
| **Delete 3D Layers** | Removes only the layers created by this add-on |

**Only the currently selected player model is processed** — other characters in the scene are not affected.

---

## Supported Models

Currently supported MCprep models:

- **Simple Player**
- **Simple Player Slim**

**Simple Player Slim** is detected automatically; you never pick the model type by hand.

---

## Compatibility & Limitations

- **Blender 5.2.0** or newer
- Requires **MCprep**
- Tested only against **MCprep-generated player models**
- Other Minecraft model importers, and hand-built Minecraft character models, are **not supported at this time**
